# 🛒 NovaMarket — Maquetación de Página Principal de Tienda Online

Proyecto de maquetación estática de la página principal de una tienda en línea, desarrollado con **HTML5**, **CSS3** y **Bootstrap 5**.

---

## 📋 Descripción

**NovaMarket** es una maqueta funcional de un e-commerce moderno. Presenta una interfaz limpia y responsiva que incluye:

- Barra superior con nombre de la tienda e ícono de carrito.
- Carrusel de banners promocionales.
- Panel lateral de categorías.
- Grilla de productos destacados con tarjetas interactivas.
- Footer informativo.

> Este proyecto es con fines académicos / de práctica en maquetación web.

---

---

## ✨ Características

- ✅ **Diseño responsivo** — Se adapta a móviles, tablets y escritorio.
- ✅ **Carrusel automático** — Banners con transición automática.
- ✅ **Tarjetas de producto** — Con efecto hover de elevación.
- ✅ **Panel de categorías** — Con efecto de resaltado al pasar el cursor.
- ✅ **CSS externo** — Estilos separados del HTML para mejor organización.
- ✅ **Variables CSS** — Paleta de colores centralizada con custom properties.

---

## 🎨 Paleta de Colores

| Variable | Color | Uso |
|---|---|---|
| `--nm-ink` | `#1f2937` | Fondo oscuro, texto principal |
| `--nm-cream` | `#faf7f2` | Fondo general |
| `--nm-accent` | `#0f766e` | Color principal (botones, precios) |
| `--nm-accent-dark` | `#0b5c56` | Hover de acento |
| `--nm-gold` | `#c9a24b` | Detalles dorados (badge, bordes) |
